# step予算 — 山から32倍ずれていた。手書き評価を抜いた

2026年8月27日。`docs/nnue-width.md` の調査が量子化のゲートで止まっている間、空いたCPUで測った副産物の記録である。**副産物のほうが大きかった。**

固定深さ6、対手書き評価、各400局。**変えたのは `--steps` だけ**で、ネットもデータもseedもレシピもgen10と同一である。

```
   step   対手書き    Elo
100,000     27.4%   -169.5    <- gen1からgen10まで、全世代がここ
 12,500     45.0%    -34.9
  6,250     58.5%    +59.6
  3,125     64.0%   +100.0    <- 山
  1,562     60.9%    +76.8
    781     51.9%    +13.0
    390     38.3%    -83.2
    195     21.1%   -228.9
```

**`docs/nnue-plan.md` の第4項を越えた。**

> **4. 50%で自己改善ループに入る。**固定深さで手書き評価に50%。これを超えるまで、教師データの生成は手書き評価のまま。

越えた手段は、新しいデータでも新しい損失項でも幅でもない。**学習を32分の1に短くしただけである。**学習時間は38分から1分になった。

## 経緯 — 探していたものではなかった

gen11(512次元)がゲートで止まり、GPUは空かないがCPUは空いた。そこで「200k stepは100k stepより良いのか」という、幅とは独立に用意してあった対照(gen10-long)を測った。

```
gen10-long vs gen10:  306 - 610 - 84 (34.8%)   Elo -109.1 ± 21.6, LOS 0.0%
```

**gen10-long の最初の100k step は gen10 とビット単位で同一である。**同じseed・同じデータ・同じ幅で、学習率スケジュールも総step数に依存しない。step 20000 の損失も step 100000 の損失も一致する。違いは後半の100k stepだけで、それが -109 Elo だった。

ここで「では100kは最適なのか」という問いが立った。`--keep-every 50000` の checkpoint がそのまま50kと150kを与えるので、**学習コストゼロで2点測れた。**

## 曲線を降りる

既存 checkpoint と、seedを揃えた短い学習(いずれも `data/mix30-v2.bin`、seed 0、`--score-weight 0.3`)。1000局の直接対決:

```
  gen10-s50  vs gen10        520 - 417 -  63 (55.2%)   +35.9 ± 21.0
  gen10-s150 vs gen10        377 - 522 - 101 (42.8%)   -50.7 ± 20.6
  gen10-long vs gen10        306 - 610 -  84 (34.8%)  -109.1 ± 21.6
```

**単調である。**そしてここから先は端を追いかけた:

```
  s50    vs s200    655 - 303 - 42 (67.6%)   +127.8 ± 22.5
  s25    vs s50     576 - 355 - 69 (61.1%)    +78.1 ± 21.3
  s12500 vs s25     621 - 318 - 61 (65.1%)   +108.7 ± 21.9
  s6250  vs s12500  630 - 305 - 65 (66.3%)   +117.2 ± 22.0
```

半分にするたび一貫して +110 前後。**これは疑うべき形である。**真の最適点に近づくなら増分は鈍るはずで、鈍っていない。6,250 step は3.6エポックしかない。この調子で外挿すれば「1 step のネットが最強」になり、それは偽である。**曲線は必ずどこかで折り返すのに、折り返していなかった。**

## 疑ったこと、潰したこと

**仮説: 出力レンジの圧縮。**学習が浅いネットは出力が小さく、枝刈りマージン(190/180/200、手書き評価のスケールで調整されている)との相性が変わるのではないか。`docs/nnue-plan.md` は「今の測定は固定深さなので勝率には効いていない」と書いているが、**マージンは枝刈りを決め、枝刈りは固定深さでも探索するノードを変える。**

測ったら**外れていた。**探索木6000局面上の出力分布:

```
  net              sd   max|x|  mean|x|  3000超
  s6250          2890    10324     2242   29.8%
  s3125          2863    10258     2205   28.9%
  gen10 (100k)   2830    10082     2209   29.4%
  gen10-long     2812     9846     2195   29.0%
```

**全step予算で実質同一。**`--score-weight 0.3` がレンジを早期に固定していて、学習を延ばしても縮まない。この機構では説明できない。

**仮説: 鎖の非推移性。**+117 と +109 と +78 と +36 を足して「対gen10で +223」と言うのは、Eloが推移的でないことを忘れた主張である。**直接測った:**

```
  s12500 vs gen10   744 - 223 - 33 (76.1%)   +200.7 ± 24.7, LOS 100%
```

鎖の予測 +223 に対し直接測定 +200.7。**鎖は崩れなかった。**定数ずれの差は 9.2点(≒17 Elo)で、効果はその12倍ある。

## 定数ずれの扱い

規律7は「この幅より小さい差を直接対決で主張するときは、両者の定数ずれを引き比べること」と書いている。今回それが効く場面と効かない場面がはっきり分かれた。

**効かない(=主張してよい)もの。**s50/s150/s200 は定数ずれがどれも +3〜+8 に固まっていて、基準の gen10 だけが -15.0 である。3本とも gen10 に対してほぼ同じ大きさのバイアス(18〜23点)を負っているのに、結果は145 Eloの幅に散った。**共通バイアスでは説明できない。**そして互いの比較(s50対s200、ずれ差3.4点)は、そもそもバイアスが打ち消し合う。

**効く(=主張できない)もの。**s50 対 gen10 の +35.9 は、両者の定数ずれの差 22.9点(≒41 Elo)より小さい。**この1本は単独では決着していない。**曲線の他の点が支えているだけである。

drift値は全部記録してある:

```
  gen10  -15.0   s150   +3.0   s25    +8.6   s3125  -0.9   s390   +2.0
  s200   +4.5    s50    +7.9   s12500 -5.8   s1562 -10.2   s195   +1.3
                                s6250  -5.4   s781   +1.4
```

## 山を挟む

s12500の対手書きが45.0%だったので、そこから下は目標指標で直接測った。**規律5のとおり、これは目標であって比較の道具ではない**が、絶対の物差しは1本しかない。

s3125(64.0%)を頂点に、両側が下がった。s781で51.9%、s390で38.3%、s195で21.1%。**両裾まで閉じた単峰である。**

**山の内側3点は分離していない。**400局の誤差幅は各 ±34 Elo で、s3125とs1562の差(23 Elo)もs3125とs6250の差(40 Elo)もその内側にある。**言えるのは「最適点は 1,500〜6,000 のどこか」までで、3,125がその中の最良だと主張することはできない。**絞るには1000局の直接対決が要る。

## 予測を外した記録

s12500が gen10 に +200.7、gen10が対手書き -169.5 なので、s12500の対手書きは +31 Elo(54%)になると**結果が出る前に書いた。実測は 45.0%(-34.9)で、66 Elo外した。**

外した理由は、**対手書きの物差しを跨いで鎖を繋いだこと**である。規律5がまさにそれを禁じている。`docs/nnue-tree-mix.md` の8月19日の追記は「同じ差を2通りに測ると gen4 以降は3〜5倍潰れる」と記録しており、今回も +201 が +135 に圧縮された。**予測の失敗が規律5の再確認になった。**

## 何が分かっていないか

**なぜ短い学習が強いのか、機構が分かっていない。**

出力レンジ仮説は潰した。val損失は逆を指した(下記)。残差指標も見ていない。**盤上の数字が7点そろって滑らかな山を描いているのに、説明が無い。**

この事業の他の発見はどれも診断と処方が噛み合っていた。点数項は「出力レンジの喪失」という診断に当てた処方だった。木の混合は「教師と消費者の分布のずれ」に当てた処方だった。**ここだけ、効果が先にあって診断が無い。**

素朴な「過学習」では足りない。過学習なら val 損失が反転するはずで、していない。1.8エポックで最適という数字も、57エポック回してなお val が下がり続けるという観測と噛み合わない。

> **8月27日、候補を一つ潰した。量子化誤差ではない。**
>
> 「学習とともに育つ量子化誤差」は、この山の候補要因として挙がっていた。L1を細かい目盛りに移してその誤差を実際に半減させ(`docs/nnue-quantization.md`)、**各step予算で世代0と世代1を直接対決させた。**
>
> **効いてはいる。**予測どおり低予算(≤1562)では 1,600局で **Elo −0.9 ± 16.4** とゼロ、高予算(≥3125)では 2,400局で **+15.2 ± 13.1** と分離した。誤差が大きいところでだけ修正が効く、という向きは当たっている。
>
> **だが小さすぎる。**同じ直接対決の物差しで、step予算そのものは gen10 → gen10-long が **−109 Elo** である。**量子化誤差はこの曲線の1割程度しか説明しない。**
>
> しかも順序が合わない。**sdの改善が最大だった step 3125(1.85倍)で、盤上は −0.9 と完全にゼロ**だった。sd比とEloの順位相関は +0.32 しかない。
>
> 目標指標でも山は高くなっていない。s3125 を世代1で対手書き400局に出して **63.5%**、記録の世代0は 64.0% である。
>
> **この節は依然として開いている。**

## val損失はこの帯域で符号ごと外れる

gen10-long の val 損失は**下がった**。最良値は最終 step (200,000) である。

```
             train      val       盤上
  100k     0.02794  0.04216      基準
  200k     0.02233  0.04000     -109.1 Elo
```

**val が下がって109 Elo弱くなった。**過学習の署名(valの反転)は最後まで出ていない。

規律1が「判定は盤上のみ」と書いている理由がそのまま出た形である。**この帯域では val 損失は使えない。**方向すら当てない。

## 記録の実体はログである

この一連の実験は無人で回した。その間、**通知の経路に、実体ログと矛盾する内容が4回現れた** — 存在しない学習ログ行、逆符号の対局結果(-27.6、ログには +78.1)、まだ始まっていない対局の結果(未来の時刻付き)、そして日本語の指示文。**いずれも `data/*.log` を検索すると0件だった。**

原因は不明である。記録として書いておく理由は1つで、**一度でもログ確認を省いていたら、偽の数字を記録に混ぜていた。**s390の偽結果(24.9%)は、本物(38.3%)と違って「裾で急落した」という筋の通る話に見えた。

**盤上の数字は `data/stepcurve.log` と `data/gen11.log` が正である。**

## 罠16 — `--keep-every` の checkpoint は無料の実験である

gen10-long を200k stepで回したとき、`--keep-every 50000` が 50k / 100k / 150k / 200k を残していた。**この4点のうち3点は、学習コストゼロで測れる別のネットである。**

step予算の曲線を最初に降りられたのは、この checkpoint があったからで、意図して残したものではなかった。**長い学習を回すときは keep-every を細かくしておくと、後から曲線が引ける。**
