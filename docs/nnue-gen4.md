## 何を変えたか

`training/model.py` の `loss()` に、勝率の二乗誤差とは別に、出力そのものへのHuber項を足した。

```
loss = mean((sigmoid(pred) - target)^2) + w * huber(pred, clamp(score, ±16000) / 600, delta=1.0)
```

両辺とも出力単位(1単位 = ポナンザ定数600点)なので、`w` は純粋な比になっていて定数を吸収しない。`w = 0` は最初の3世代が使った損失と算術まで同一で、既定値である。

**なぜこの形か。**gen3までの行き止まりは `docs/nnue-search-distribution.md` に測ってある。`sigmoid(score/600)` は3300点より上を要求しないので、ネットワークは範囲を失う。範囲を買い戻す方法はポナンザ定数を上げることだが、それは3組の対局すべてで否定された(C600 > C1200 > C1800、LOS 100%)。**シグモイドを引き伸ばすと決着帯の分解能が犠牲になり、そちらのほうが重い。**

点数空間の項は、その綱引きの外側から尾部に圧力をかける。定数は600のままなので、決着帯のシグモイドは動かない。

`SCORE_HUBER_DELTA = 1.0`、`SCORE_CLAMP = 16000`。どちらも今回は振っていない。**変数は1度に1つ。**

## 指標は何を言ったか

この項目が本題である。この事業では**残差の読みと盤上が5回食い違った**(`docs/nnue-search-distribution.md`)。6回目がどうだったか。

**「詰みを除いた探索木上の残差sd」は当てた。**2222 → 1202 の改善を予想し、盤上は +313 Elo と答えた。向きが合い、しかも大きさも「小さくない改善」で一致している。gen3に続いて2回連続で外していない。**この基準を採用した判断はここまで持ちこたえている。**

**「決着帯の残差sd」はまた外した。**598 → 745 は劣化で、この指標だけを見ればgen4は却下される。**却下していれば、4世代で唯一針を動かした実験を捨てていた。**`docs/nnue.md` の「足切りであって合格証ではない」は、いま**足切りとしても機能していない**。手書きの653を下回ることを条件にすると、gen4は落ちる。

読み方を1つ更新する。**決着帯は監視対象であって条件ではない。**gen4の745は、手書きの653に対して14%の劣化で、その代わりに尾部を3.4倍買っている。C=1800は決着帯を1242(90%の劣化)まで壊して尾部を1829しか買えなかった。**問題は決着帯を失うことではなく、失った分に見合うものを買えているかである。**

## この項の値段

`--score-weight` は無料ではない。

- 決着帯の分解能を14%払う(上記)
- 損失に項が1つ増えるので、**訓練lossとval lossが重み間で比較できなくなる**。`w` を振る実験では、盤上か残差でしか順位が付けられない
- ハイパーパラメータが2つ増える(`--score-weight` と `SCORE_HUBER_DELTA`)。gridは掛け算で増える

それでも、`data/gen3.bin` をそのまま使って32分の学習で +313 Elo である。同じ期間に検討した他の道(深さ8での再生成77時間、教師分布の入れ替え)より2桁安い。
